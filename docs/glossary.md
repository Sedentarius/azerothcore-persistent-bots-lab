# Glossary

## Altbot

A persistent player-created bot character associated with a normal account. In this project, important companion characters should use Altbots rather than disposable random-bot population logic.

## Bot-hour

One bot online for one hour. One hundred bots online for four hours produce approximately 400 bot-hours of exposure.

## Cohort

A group of bots introduced under a shared creation policy and tracked as a population over time.

## Effective configuration

The sanitized configuration actually loaded by the running server, not only a template, environment variable, or intended value.

## Generated resource

Gold, food, equipment, ammunition, reagents, bags, repairs, or similar resources created by maintenance or convenience logic without a normal in-world source.

## Legitimate provenance

A traceable in-world cause for a resource or state change, such as loot, quest reward, vendor transaction, crafting, trade, Auction House settlement, trainer purchase, or earned XP.

## Observation

A recorded event or pattern seen during normal operation. It may motivate an experiment but does not by itself establish causality.

## Experiment

A declared test with a question, protocol, known conditions, measurements, and interpretation rules.

## Realm stage

The project's progression state controlling which era content is intended to be available. Realm stage is separate from the underlying 3.3.5a core/client version.

## RNDBOT / random bot

A PlayerBots-managed population character that may be created or maintained by random-bot systems. Project rules restrict behaviors that would rewrite persistent progression.

## Server runtime

Elapsed time while the world server process is running.

## Session

One research-relevant interval of world-server execution, identified by a stable `SES-*` ID.

## Upstream

An external source repository on which this project depends, such as AzerothCore or PlayerBots.
