# Licensing policy

Licensing is not finalized for the project-owned material in this repository.

This is deliberate. The repository may contain several different classes of work:

- original documentation and data definitions;
- original scripts and analysis code;
- patches that modify GPL-licensed upstream software;
- metadata and datasets derived from server observations;
- references to third-party projects with their own licenses.

AzerothCore currently distributes its core under the GNU General Public License version 2 text. Any project patch derived from an upstream component must respect that component's actual license and notices.

Until a project-wide licensing review is completed, do not assume that all files in this repository share one license merely because they are stored together.

## Non-negotiable distribution boundary

The project does not grant rights to Blizzard Entertainment assets and will not distribute World of Warcraft client binaries, MPQ archives, art, audio, or other proprietary game assets.

## Planned action

Before publishing reusable project code or derivative patches, record:

1. the license of each upstream dependency;
2. the appropriate SPDX identifier for each project-owned file class;
3. whether documentation/data use a separate license;
4. required copyright and attribution notices.
