# Protocol

## Preconditions

List required release, configuration, population state, and QA state.

## Procedure

Number the actions another developer must reproduce.

## Exposure / stopping rule

Define runtime, bot-hours, number of runs, event count, or another stopping condition before interpreting the result.

## Allowed intervention

State whether a human may play, issue bot commands, recover stuck agents, restart the server, or modify configuration during the run.

## Failure handling

Define what invalidates a run and what is recorded as a legitimate failure outcome.
