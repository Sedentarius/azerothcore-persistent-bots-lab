# Experiments

Controlled experiments use stable IDs such as `EXP-001`.

An experiment directory should contain enough information to answer:

1. What question was tested?
2. What was predicted?
3. What exact realm release and configuration were used?
4. What population and exposure were used?
5. What was measured?
6. What data support the result?
7. How was the analysis produced?
8. What limitations remain?

Use `experiments/TEMPLATE/` when starting a new experiment.

Do not create empty experiments merely to reserve interesting topics. Add an experiment when there is a real protocol to run.
